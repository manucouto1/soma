## Core Capabilities

<CardGrid>
  <Card title="Computational Graphs" icon="rocket">
    Define research pipelines as executable, differentiable graphs with automatic caching and lazy evaluation.
  </Card>
  <Card title="Data Virtualization" icon="document">
    Every intermediate result is a virtual reference materialized on demand. Like Denodo, but for computation.
  </Card>
  <Card title="Hyperparameter Optimization" icon="setting">
    Search spaces co-located with filters. Grid, random and Bayesian (TPE) search, with median and percentile pruning.
  </Card>
  <Card title="Agentic Flows" icon="star">
    An agentic flow is just a graph whose nodes are effectful. A pipeline is a tool for an agent; an agent is a node in a pipeline — with the same caching, schema checks and search spaces.
  </Card>
</CardGrid>
