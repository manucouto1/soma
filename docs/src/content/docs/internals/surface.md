The rest of this section cuts horizontally, by crate. It answers *what is in
`soma-runtime`?* and it answers it well. It never answers *how many ways are
there to build a graph?*

The answer was six, and nothing in the repo said so. Six ways to build a graph,
six to execute one, eight levers on the cache, five to configure a search, nine
to render a diagram. Each was defensible when it was added. Together they are
the reason the Python API has to be looked up rather than learned.

This page is that count, taken mechanically. It exists to be *compared against
itself over time*: a row that disappears is a concept a reader no longer has to
hold.

## How it is built

Generated by `docs/scripts/gen-surface.mjs` from four sources, none of which
involve judgement:

| # | Source | Gives |
|---|---|---|
| 1 | `__all__` in `soma/__init__.py`, `agentic.py`, `library.py`, `viz/__init__.py` | every exported name |
| 2 | `#[pymethods]` blocks across `soma-python/src/*.rs` | every method the extension classes expose |
| 3 | the class body of `soma/_graph.py` | the methods assigned onto `Graph` from Python |
| 4 | `add_class` / `add_function` / `add` in the `#[pymodule]` of `soma-python/src/lib.rs` | the free functions on `soma._soma` |

Regenerate with `node scripts/gen-surface.mjs` and commit the result. The page is
committed rather than built so that a symbol disappearing shows up in a diff.

### Two columns worth reading carefully

**Aliases.** A method whose entire body is a call to a sibling method is
reported as an alias. That is a syntactic test, not a semantic one, and it is
how `Graph.connect` — a one-line forward to `Graph.edge` — became visible as a
duplicate path rather than a convenience.

**Usage counts.** These are grep, over tests, notebooks, docs and examples. A
name inside a string or a comment counts; dynamic access is invisible. They are
here to find the **zeroes**, because a symbol nothing in the repo names is a
symbol whose cost is certain and whose value is not. Treat a low count as a
question and a zero as a question worth answering; neither is a verdict.

The generated tutorials under `docs/…/tutorials/` are excluded from the corpus.
They are rendered from `notebooks/`, and counting both doubles every number.
